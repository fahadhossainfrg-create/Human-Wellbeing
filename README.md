# Human Wellbeing

An interactive geography website exploring:

- human wellbeing and its seven dimensions
- regional disparities
- indicators and the Human Development Index
- sustainable development and the SDGs
- poverty, disadvantage and NGOs
- population pyramids and demographic change

The site includes 36 detailed topics, interactive navigation, search, progress tracking, quick checks, dark mode, responsive layouts and links to authoritative sources.

Live site: https://fahadhossainfrg-create.github.io/Human-Wellbeing/
